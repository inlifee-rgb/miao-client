MIAO for WorkBuddy · macOS 安装说明
======================================================================

【系统要求】
  macOS 11 (Big Sur) 及以上
  Apple 芯片（M1 / M2 / M3 / M4）

  注：Intel 芯片的 Mac 暂时请用下方的「免安装方案」，原生 Intel 包后续补。


【安装三步】
  1) 解压 MIAO-mac-x.x.x.zip
  2) 把 MIAO.app 拖进「应用程序」文件夹
  3) 第一次打开不要双击！
     在「应用程序」里【右键】点 MIAO → 选「打开」
     弹窗再点一次「打开」

     之后就正常了，以后双击即可。


【情况一：提示「无法打开，因为无法验证开发者」】
  系统设置 → 隐私与安全性 → 拉到最下面
  → 看到「已阻止使用 MIAO」→ 点【仍要打开】
  → 再确认一次「打开」

  只需做一次。


【情况二：提示「MIAO 已损坏，应移到废纸篓」】
  这是 macOS 给下载文件加的隔离标记，不是真的损坏。
  打开「终端」（启动台搜 Terminal），粘贴执行：

      sudo xattr -dr com.apple.quarantine /Applications/MIAO.app

  输入开机密码（输入时不显示，输完回车），然后重新打开 MIAO。


【为什么要这样】
  我们没有购买 Apple 开发者签名（99 美元/年），
  未签名的应用会被 macOS 拦一次。
  上面的操作只需要做一遍，之后一直正常。


【不想装 App？两种替代方案】
  A. 网页控制台（浏览器打开，查余额/用量/兑换）
     http://103.236.73.61:18300/

  B. 一键配置脚本（只配置模型，不装 App）
     双击 miao_configure_mac.command
     输入你的密钥（sk- 开头）
     脚本会自动写入 ~/.workbuddy/models.json
     然后重启 WorkBuddy 即可


【使用】
  打开 MIAO → 输入密钥（找你的销售/管理员要）
  → 点「配置到 WorkBuddy」
  → 完全退出 WorkBuddy（⌘Q）再重新打开
  → 模型列表里出现 Miao:* 系列即可用


【遇到问题】
  把截图 + 系统版本（苹果菜单 → 关于本机）发给我们。
